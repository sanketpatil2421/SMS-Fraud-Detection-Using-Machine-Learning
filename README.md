# 🚀 Features

✔ Real-time SMS fraud prediction

✔ TF-IDF text preprocessing

✔ Machine Learning model (Naïve Bayes / SVM / Logistic Regression)

✔ Interactive frontend using Streamlit / Flask

✔ Clean UI for user input

✔ Accurate model with high precision & recall

✔ Deployed locally or on cloud platforms


# 🖥️ Web App (Frontend)
User Inputs SMS text

The app instantly predicts:

✔ Ham (Safe Message)

❌ Spam (Fraudulent SMS)

# ▶️ Installation & Running the Project:- 

1. Clone the Repository
   
git clone https://github.com/your-username/SMS-Fraud-Detection-Using-Machine-Learning.git
cd SMS-Fraud-Detection-Using-Machine-Learning

3. Install Dependencies
   
pip install -r requirements.txt


If any error occurs:

pip install flask nltk scikit-learn pandas numpy

3. Download NLTK Stopwords
   
python -c "import nltk; nltk.download('stopwords')"

5. Run the App
   
python app.py


Open in browser:

http://127.0.0.1:5000


python.app.py
